# Library Management System

A simple command-line Library Management System built with Python to practice Object-Oriented Programming and basic software engineering concepts.

## Features

- Add books
- Support Printed Books and EBooks
- View available books
- Search books by ID, title, or author
- Borrow books
- Return printed books
- Input validation
- Unique book IDs
- Object-Oriented Design
- Modular project structure
